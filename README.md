# Yoko Shop

ქართულენოვანი ონლაინ მაღაზიის სტატიკური საწყისი ვერსია. პროექტს არ სჭირდება build პროცესი ან დამატებითი პაკეტები.

## გაშვება

გახსენი `index.html` ბრაუზერში, ან გაუშვი საქაღალდეში ნებისმიერი სტატიკური ფაილების სერვერი. პირველი გვერდი რეგისტრაციის ფორმაა; წარმატების შემდეგ მომხმარებელი `shop.html`-ზე გადადის.

## რედაქტირება

- პროდუქტების სახელები, ფასები და სურათები შეცვალე `script.js`-ის `products` სიაში.
- სტილები შეცვალე `styles.css`-ში.
- მაღაზიის გვერდის ტექსტი და საკონტაქტო ინფორმაცია შეცვალე `shop.html`-ში.
- რეგისტრაციის გვერდის ტექსტი შეცვალე `index.html`-ში, მის სტილებს — `auth.css`-ში.
- ბრენდის ლოგოს ფაილია `logo.png`.

მთავარი ბანერის, კატეგორიებისა და ამბის სექციაში დამატებითი ფოტოები ამოღებულია. კატალოგში პროდუქტის ფოტოები დატოვებულია, რადგან ისინი ნივთების საჩვენებლად გამოიყენება.

საწყისი რეგისტრაცია დემო რეჟიმში მუშაობს: პროფილი ინახება ამ ბრაუზერის `localStorage`-ში, პაროლი კი არც ინახება და არც იგზავნება. პროფილის ღილაკიდან შესაძლებელია პროდუქტის დამატება ან წაშლა. პროდუქტები და კალათა ამავე ბრაუზერში ინახება; სხვადასხვა მოწყობილობასა და მომხმარებელს შორის მონაცემები არ სინქრონდება.

ეს ვერსია არ შეიცავს ნამდვილ მომხმარებლის ანგარიშებს, სერვერზე პროდუქტების შენახვას ან შეკვეთებისა და გადახდების დამუშავებას. რეალური გაყიდვებისთვის საჭიროა სერვერი, უსაფრთხო ავტორიზაცია, მარაგების მართვა და გადახდის პროვაიდერთან დაკავშირება. პროდუქტების მაგალითები, ფასები, ფოტოები, ტელეფონის ნომერი და ელფოსტა დემო მონაცემებია.
